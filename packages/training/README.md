This private crate retains the synthetic CPU `f64` path with Burn `0.22.0`.
Rust contracts, candidate composition and baseline selectors support the native arena delivery.
The full learner remains incomplete.
[Unverified] Shared418, paired belief/spatial coordination and strict diagnostic artifact/checkpoint sources are prepared but remain uncompiled and unrun.
The [compatibility plan](../../_spec/_plans/burn-flex-compat.md) records the earlier bounded milestone.
The [native-runner contract](../../_spec/ml/native-runner.md) records the completed bounded baseline delivery.

The published native baseline passed its matching-source gate and all three closing reviews.
The ledger has a separate [verification and closing-review record](../../_spec/_plans/native-economic-ledger.md).
The baseline receipts do not verify the ledger.

## Library boundaries

- `contracts`: closed authorized views, seven action families and complete canonical action-array keys.
- `evidence_tables`: paired numerical counts, qualified likelihoods and post-aggregation weighting.
- `accounting_kernel`: one-source accounting flow and counts-independent reachability, not a joint estimator.
- `banded_joint`: owned normalization, exact categorical conditional PMFs and untempered expansion.
- `feature_input`: checked ordered boundary innovations and detached own-lineage inputs.
- `feature_manifest`: exact 418-coordinate metadata, not an encoder.
- `features`: source-only shared numerical 34+4×84+12+36 encoding and detached flattening.
- `numerical_belief`: source-only paired reduction, shared Marine adapter and calibrated readout copies.
- `artifact_bytes`, `artifacts`, `checkpoint`, `policy_weights`: source-only strict canonical admission and detached scalar weights; fitted inference stays fail-closed.
- `joint_math`: checked numerical masks, global normalization and summary-only readouts.
- `joint_accounting`: canonical all-source raw accounting with shared buffers and independent Boolean reachability.
- `learner_math`: finite f64 policy statistics and arithmetic SGD proposals, not update permission.
- `candidates`: profile-B composition with native planning helpers supplied through `PlanningOracle`.
- `policy`: `pass-v1`, `first-v1` and integer-seeded `seeded-v1` selectors, including pass.
- `ledger`: strict economic boundaries, atomic recipient histories and paid-basis conservation.
- `score_synthetic_f64`: the retained fixed Burn model, not a learned arena policy.
- `protocol`: the standalone numerical compatibility surface.
- `transition_tables`: numerical source witnesses, fractional counts, group-qualified backoff and source normalizers.

Composition limits are four actions, 2048 attempted extensions and 512 retained candidates including pass.
Node supplies native geometry, append failures, anchors and one-action costs.
Rust owns composition, reservations, canonical identity and cumulative spend.

## Ledger foundation

The [ledger contract](../../_spec/ml/native-economic-ledger.md) defines the bounded ledger delivery.
The new `ledger` module owns closed economic DTOs, durable own-unit/mine identities, authorized observations and exact paid-basis accounting.
Native helpers supply rule defaults, costs, income entitlement and causal facts.
Rust does not duplicate native income or movement rules.
The explicit settlement thresholds are **turn 1 → 1**, **turn 11 → 2**, and **turn 21 → 3** nominal minerals per seat and next-turn gas capacity.
Turn-0 initialization grants nothing.
A game-ending turn-start check opens no next playable turn or additional settlement grant; its raw final snapshot belongs to separate preservation regressions, not the normal income schedule.
Own paid investment, non-CC replacement value and native unit cost remain distinct.
Enemy sightings and witnessed destruction do not establish exact enemy inventory or spending.

One ledger-work allowance covers both recipients in each reconstructed window.
Initial history belongs to the first window's allowance.
RPCs and helper calls cannot renew that allowance.
This bounds ledger work, not the deferred full-feature training decision.
Economic verification does not certify policy selection or learner readiness.
The arena's separate verified-terminal closeout excludes unused actual credit without changing these raw histories.
Full418/posterior/promotion execution, the complete learner/controller and calibration acceptance remain deferred.

## Learner mathematics

The [F2 contract](../../_spec/ml/native-learner-math.md) defines stable softmax/log probabilities, explicit-uniform sampling, streamed decision statistics and atomic summed statistics for at most 64 decisions.
Scalar f64 functions return detached proposals using the frozen `.001` learning rate and `.0001` L2 term once.
They never commit weights, classify eligibility, draw RNG values or run native episodes.
Independent scalar finite differences and test-only Burn/F64 autodiff and SGD check the numerical results.
These checks do not establish full feature semantics, native authority, decision-budget admission or training readiness.

## Point-source accounting

The [F3 contract](../../_spec/ml/native-accounting-kernel.md) defines distinct accounting tuples, positive suffix flow and independent Boolean reachability for one hypothetical source.
The kernel keeps its denominator unconditioned and returns raw retained evidence mass without posterior normalization.
Native-derived rule tables supply numeric income and gas values; their structural validation does not authenticate a grant or observation.
All operations precharge the caller's existing shared work meter.
This primitive does not implement the joint estimator, spatial support, fitted tables, calibration or whole-decision resource admission.

## Numerical joint readouts

The [F4 contract](../../_spec/ml/native-joint-math.md) checks supplied numerical support and normalizes already aggregated masses once.
Readout temperatures apply only to a private copy and return means, quantiles, balance and material uncertainty.
The original joint remains unchanged; no tempered joint escapes for recursive reuse.
Mask certainty includes all supplied supported states, even states with zero model probability.
These numerical checks do not authenticate public support, source aggregation, fitted temperatures or native observations.
The standalone invoice does not establish that history, transitions and all candidate features fit the shared planning budget.

## Numerical transition tables

The [F5 contract](../../_spec/ml/native-transition-tables.md) builds ordered fractional counts from supplied numeric groups and derives distinct contributing-group qualification.
Its source normalizers retain canonical count order and use checked growth metadata without allocating complete joint flows.
The 8,192 occupied-row ceiling applies across all cohorts; explicit vector growth also accounts for temporary copies.
Numeric source witnesses do not prove trustworthy labels, native execution, independent ancestry or authenticated artifacts.
This module does not run empirical fitting or admit a complete offline driver, joint evaluator or planning schedule.

## Raw joint accounting

The [F6 contract](../../_spec/ml/native-joint-accounting.md) aggregates numerical prior sources through qualified numerical tables using four shared buffers.
Supported zero-PMF sources propagate Boolean reachability without consulting fitted counts or qualification.
The narrow private table bridge preserves existing public results and work invoices.
The result stops before qualified evidence likelihood and global normalization; it is not a complete estimator or an implicit likelihood-one model.
Canonical contribution order remains fixed, and dense inputs may exhaust the same caller's work allowance.
These checks establish no native bindings, authentic public support or complete-window resource admission.

## Paired numerical evidence

The [F7 contract](../../_spec/ml/native-evidence-tables.md) derives transition and evidence counts from one supplied compound group roster with the same complete-group weights.
Evidence uses destination cohorts and shares the transition tables' occupied-row ceiling.
Weighting moves the raw mass/mask buffers, preserves every accounting-mask bit and stops before global normalization.
The explicit zero-innovation bypass validates context first; fit-time zero codes still contribute counts and qualification.
These numerical checks do not run empirical fitting or authenticate labels, ancestry, artifacts, calibration or public support.

## Categorical banded joints

The [F8 contract](../../_spec/ml/native-banded-joint.md) normalizes owned weighted buffers once and stores complete conditional PMFs in at most 247 bank/band components.
Zero-mass components disappear without pruning any supplied support bit.
Expansion produces a detached untempered joint and validates it without another global division.
The representation uses no Gaussian approximation, probability floor or residual repair.
Ownership savings remove actual replacement allocations and copies; they do not discount work charges or establish composed-window admission.

## Preparation

Rust owns the learner, arena, tests, and verification.
Node hosts only the adapter to the existing TypeScript engine.
Use pnpm to install that adapter and existing JavaScript workspaces.
Provision Rust `1.95.0` with rustfmt and Clippy through mise or rustup.
A native C linker is required; a scoped Zig `0.15.2` compiler also works.
Set Cargo's target linker and `CC` to your Zig C wrapper when the host lacks a toolchain.
Do not place machine-specific tool paths in the repository.

```sh
pnpm install --frozen-lockfile
cargo fetch --locked
cargo xtask check
cargo run --frozen -p arena -- smoke
```

The gate builds the Rust workspace before integration tests.
Oxlint checks the thin Node adapter and its TypeScript/MJS tests.
tsgo checks TypeScript inputs; Node runtime tests execute the MJS metadata oracle.
The existing engine retains its own strict compiler profile.

The arena calls this Rust library directly.
The Node adapter accepts only versioned fixed fixture identities and native action data.
It never loads model paths, runs Cargo, installs dependencies, or substitutes JavaScript scoring.
Framework tensor operations, autodiff, SGD and Burnpack supply the retained compatibility path and test-only numerical oracles.
The learner-math module uses scalar f64 arithmetic and does not implement a production Burn learner.
Only synthetic Rust tests update fixture weights.

`cargo xtask check` retains logs and a source-bound receipt in a fresh temporary directory.
Set `TRAINING_RECEIPT_PARENT` to select an existing receipt parent.
All required checks must pass before reviewers become eligible.
Python is absent from our implementation; upstream dependencies may use it.
