# Development-only `sbx` smoke

`host-smoke.sh` runs a **no-input, no-KUnit** CLI check on the existing shared daemon. It is not a host guard, service-isolation check, provenance check, or F9 Gate0/G1/5c/Native result. It uses the operator's existing `HOME` and `sbx` configuration. **Request fresh approval for one exact invocation before using it on the host.** Earlier approvals covered only their individual attempts, including the later successful development-only smoke. No `mise` task invokes this script.

The required `--confirm-dev-shared-daemon` flag acknowledges the selected development scope; it is not host authorization. Pass an absolute path to the installed `sbx` executable using `--sbx`. The optional `--create-seconds` lowers the default 60-second creation deadline for tests or a separately approved invocation. The script lists names (at most 64 KiB), generates a random name, creates a mountless `shell` sandbox with `--pull never --skills off --deny-network '**' --cpus 1 --memory 512m`, executes `/bin/true`, removes **only the confirmed owned name**, then checks it is absent from a complete names-only listing. Ordinary create, exec, listing and removal use `timeout --kill-after=2s`. It never uses `rm --all` or attempts removal after ambiguous creation.

The optional `--instrumented-debug ABSOLUTE_PRIVATE_DIRECTORY` uses [create-debug.mjs](create-debug.mjs) with **Bun 1.4.0** on `PATH` for **create only**. The helper uses dependency-free Node builtins. It invokes the installed CLI with global `-D`, samples only that CLI child's `/proc/<pid>/stat` and `wchan` after matching its start-ticks string, and bounds its monotonic create deadline to 1–60 seconds with direct-child TERM followed by KILL after two more seconds. It captures stdout and stderr into a **new**, owner-only `0600` file named `ATTEMPT_NAME.debug.log` under a pre-existing user-owned `0700` directory, keeps at most 1 MiB, and drains/discards any additional bytes. It walks canonical absolute directory components with no-follow directory opens, rejects untrusted owners and writable parents except root-owned sticky directories, and creates the log exclusively relative to the validated directory descriptor through `/proc/self/fd`. The terminal prints only phase times, PID/start ticks, process states, captured/dropped byte counts, and the private filename; it does **not** print raw debug output. Debug output **may include credentials, paths or other sandbox details**. Inspect the private file locally before sharing a redacted excerpt. Do not put it in the repository, publish it, or treat `-D` as a sandbox-containment control. No debug file proves a request reached the daemon; a missing completed `POST` remains `UNKNOWN`.

The instrumented mode needs **separate exact host approval** for one VM create/exec/removal attempt, access to the installed CLI and its existing authentication, private debug-file retention, and PID-scoped `/proc` sampling. Neither choosing this design nor passing `--confirm-dev-shared-daemon` grants that approval. The CLI's `-D` output on the installed v0.50.0 binary has not been inspected; fake-CLI tests only verify the wrapper's bounded local behavior. Do not restart/reset the shared daemon or modify its policy or credentials to make the smoke pass.

`ATTEMPT_NAME` identifies the attempted name, not a confirmed VM. `CREATE_UNCONFIRMED_NAME` and `OWNERSHIP_UNCONFIRMED_NAME` require operator reconciliation, not a retry or automatic removal. `REMOVE_UNCONFIRMED_NAME` requires reconciliation even if the removal request exited successfully. `NAME_ABSENT_AFTER_RM` means only that the name is absent from a completed names-only listing. `RESULT=DEV_SMOKE_ONLY` requires successful create, exec, removal request and final listing; it proves only those CLI operations, not host containment or cleanup of transient artifacts. Network-deny effectiveness and kit behavior are not proved by this smoke.

Run the fake-CLI suite offline without the real daemon or credentials. The fixtures use absolute Bun shebangs and never invoke the installed `sbx`, `mise`, Cargo, or a VM:

```sh
bun test tooling/sbx-smoke/tests/host-smoke.test.mjs
```
