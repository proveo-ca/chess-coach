# Whole-match checked barriers

Status: IMPLEMENTATION / SYNTHETIC VERIFICATION REQUIRED / NO EXECUTION OR TRAINING GRANT.

The child owns the canonical whole-match loop.
The in-envelope owner reconstructs every initial/open/settled boundary and verifies compact decisions before releasing the child.
The wire carries no executable, source, reference, model-path, feature tensor, eligibility flag or renewed clock origin.
Each closed request/reply binds one attempt and contiguous ordinal.
The owner acknowledges the digest of exactly one previously verified reply.
No retry, alternate plan, replacement queue or implicit replay exists.

## Ordering

1. Start binds the already-durable descriptor and stream prefixes.
2. Ready carries canonical initialization and private provenance binding.
3. Ready acceptance releases the child's native open.
4. Open acceptance releases the first required permit, or truthful terminal/exhaustion/cap completion.
5. Required decisions run white then black.
6. Recorded White uses the trusted source without a permit.
7. Each candidate/strategic result waits for exact reconstruction and ACK.
8. The final decision ACK releases one whole-pair admission and settlement.
9. Settlement acceptance releases the next child-owned iteration.
10. Completion compares exact ACKed IDs, streams, source prefix and the owner-derived stop.
11. Normal completion requires child/scorer close, EOF and successful natural reap.

Both sides plan from the same precommit state.
First-side ACK commits its known RNG prefix but exposes no first-side queue or spend to the other side.
The owner feeds reconstructed candidate features to both C12 learners before releasing the ACK barrier.
It retains compact journals and releases temporary feature matrices before the next decision.
The owner reexecutes native pair admission to distinguish typed actual queue denial from malformed input or unrelated exceptions.
Only the exact candidate member or exact trusted recorded-White queue can establish a native-rejection return.
Strategic/schema/protocol/source/learning failures abort all.

## Stops and clocks

Terminal outcome comes from actual canonical native transitions.
Exhaustion comes from the trusted corpus at the current nonterminal ordinal.
Progress counters come from actual open/settlement results.
The unchanged caps are 64 windows and 128 recorded native plies.
The canonical 45-turn rule can make these safety caps unreachable in ordinary canonical play.
Synthetic counter tests do not claim a real cap-reaching canonical rollout.

The owner timestamps complete frames before parsing.
The child never compares its process-local `hrtime` values with serialized owner timestamps.
The actual separate-process fixture exposed those clocks as noninterchangeable in the selected development Bun runtime.
The worker maps each authorized permit to a local safety guard without changing its decision identity or journal.
Its launch argument supplies a bounded remaining duration for the local work guard, not a new owner clock origin.
Owner receipt/deadline checks remain authoritative even when launch or barrier latency makes a child safety guard end later.
It starts each fixed 10-second permit before writing it.
Timely raw receipt and subsequent reconstruction have distinct deadlines.
Verification/barrier/learning time consumes the original work budget.
Candidate timeout requires the owner's outstanding candidate permit, original raw deadline and an owned stop/reap receipt with no competing transport fault.
Stop the match and its frozen-scoring descendants before finishing the known ACKed prefix in both still-owned learners.
Opponent/startup/match/ambiguous timeouts abort all.
Require both learners' natural close/reap before returning any proposal for atomic completion.
Do not infer eligibility from `CompletionValues`, stop labels or exception strings.

The SQLite adapter and private evidence target remain separate publication boundaries.
No source-only match result establishes operational durability, resource qualification or `trainingReady:true`.
