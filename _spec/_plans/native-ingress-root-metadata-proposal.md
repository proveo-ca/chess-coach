## Exact proposed scope and expected predicates

The **only three installed-path metadata targets** are ancestor `/tmp`, parent `/tmp/opencode` and retained M2 directory root `/tmp/opencode/f9-host-rust-1.95.0-m2`. Independently select the following refusal predicates **before** observation: `/tmp` must be a nonsymlink directory owned by UID 0 with `(mode & 0o7777n) === 0o1777n` (new conservative proposal, **not** a fact established by M2); parent must be a nonsymlink directory owned by the executing effective UID with `(mode & 0o022n) === 0n` (M2 precheck); root must be a nonsymlink directory owned by the same effective UID with `(mode & 0o7777n) === 0o700n` (**stricter** than M2's recorded permission-bits-only `mode & 0o777` check). This observation does **not** establish immutable custody, a current capacity/quota, a toolchain identity or a captured byte closure.
