# Disposable container access probe

Contract: [`_spec/training-container-access.puml`](../../../../_spec/training-container-access.puml). The earlier packet2 runtime spec and its index remain frozen.

Run the issued command once on the dedicated HOST volume, as the normal user, without sudo. Do not run it while anyone is modifying the mount, volume, Docker configuration, or SELinux policy/enforcement. The probe requires the repaired owner/mode and recorded volume identity, SELinux enforcing mode, and the observed `var_lib_t` context on the volume and the disposable directory and seed. It stops rather than relabeling if any precondition fails.

The probe inspects the retained packet2 image for `linux/amd64` locally and rejects image-declared volumes before creating anything. If Docker does not support platform-specific inspection, the probe stops without a fallback. It uses `--pull=never`, `linux/amd64`, `--network=none`, `--log-driver=none`, CPU-only `runc`, and UID/GID `1000:1000`. It inspects the configured confinement and sole private bind before starting a read-only-root container. The shell enters the bind and verifies its device and inode before it reads the seed or writes the reply. The host confirms the process label and exit state, then verifies the reply. A PASS applies only to this directory, context and CPU-only container. It does not verify the NVIDIA runtime or any future campaign mount. Enforcement and labels are sampled at checkpoints, not continuously attested.

The launcher caps wall time at 75 seconds, plus a 2-second kill grace. Each subprocess has its own timeout; timing out a Docker client does not cancel daemon work. The probe prints the exact name and path before any mutation. Cleanup removes only a confirmed full container ID and uses held directory descriptors for the owned probe files. If creation or removal is uncertain, cleanup leaves the directory in place. Do not retry, prune, relabel, or manually clean up under this authorization. Return all `Executor:` lines, even on a blocked result or interruption. A blocked result does not by itself establish a SELinux denial.

No campaign root, retained payload, capacity observation, or training state is touched. The command embeds source without a HOST fetch. It starts Bun from `/` with an inert config and a clean environment. Issue it only after matching the embedded bytes to the checked published blob. Its publication is not approval for subsequent HOST preparation or training.
